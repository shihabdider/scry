## Details

## Parent issue

#0002 (.ous/issues/0002-bootstrap-mv3-side-panel-shell-with-cmd-ctrl-k-toggle.md)

## What's wrong

The initial report included shortcut close failure, but QA clarified that Command+K does close the Scry side panel on the user's Chrome 147 install. QA then clarified the desired model: Command+K should open/refocus only, and close should move to a separate shortcut.

## What I expected

The close behavior should be handled by a dedicated close shortcut instead of the open/refocus shortcut.

## Steps to reproduce

1. Load Scry as an unpacked Chrome extension in Google Chrome 147.0.7727.101 on macOS arm64.
2. Open the Scry side panel from its assigned keyboard shortcut or extension action.
3. Press the assigned Scry shortcut again.
4. Observe whether the Scry side panel closes in the current window.

## Blocked by

None — can start immediately.

## Additional context

Chrome's MV3 docs say side panels can be opened from a keyboard shortcut in Chrome 116+, `sidePanel.close()` is Chrome 141+, and close events are Chrome 142+. The reported Chrome 147 environment supports all of these APIs, and this is a personal extension, so no older-version fallback is required for this issue.
