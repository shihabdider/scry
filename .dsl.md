# Domain language

## Terms

- **Public mode** — A Scry search mode reachable by `Tab` / `Shift+Tab`; currently `recent`, `closed`, and `deep`.
- **Hidden mode** — A Scry search mode not reachable by the public mode cycle; `favorites` is entered by command instead.
- **Favorite** — A user-saved URL stored locally by Scry in `chrome.storage.local`, unique by Scry's normalized URL key.
- **Favorites mode** — The hidden search mode for saved favorites. It is entered with `:f` through `:favorite` + `Enter`, clears the command input, and exits with `Tab` back to the previous public mode.
- **URL-bearing context target** — A right-click context target that Chrome exposes with a URL, including page, link, image, video, audio, and frame.
- **List-selection mode** — The results-focused keyboard mode where selected-row actions such as `y copy`, `c edit URL`, `x remove`, and `u undo` are available.
