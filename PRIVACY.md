# Scry Privacy Policy

Last updated: July 2, 2026

Scry is a local Chrome extension for searching browser history, recently closed tabs, and user-saved favorites.

Scry does not collect, sell, share, transmit, or externally store user data. Scry does not use analytics, does not make external network requests, does not inject content scripts, and does not request host permissions.

## Data Scry uses

Scry uses Chrome extension permissions only to provide its local command-palette features:

- **History**: reads Chrome history URLs and page titles so users can search previously visited pages locally.
- **Sessions**: reads recently closed tabs and windows so users can search and reopen recently closed pages.
- **Tabs**: opens selected results in new tabs and reads the active tab URL/title only when the user explicitly saves the current tab to Scry favorites.
- **Storage**: stores Scry-only local data, including favorites, shortcut settings, and local ranking preferences.
- **Context menus**: adds Scry menu items so users can explicitly save pages, links, images, videos, audio, or frames to local Scry favorites.

## Storage and sharing

All Scry data is stored locally on the user's device in Chrome extension storage. Scry does not send browsing history, favorites, settings, tab data, or ranking data to any server.
