## Summary

Closed as obsolete: Scry no longer uses the Chrome Side Panel for the Command+K flow, so a dedicated side-panel close shortcut is no longer needed.

## Details

## Parent issue

Reported during QA session

## What's wrong

Scry currently treats the main shortcut as a toggle. That makes focus recovery janky: the shortcut users expect to bring them back into the search box can close the side panel instead.

## What I expected

Scry should have one shortcut whose job is to open or refocus the side panel search, and a different shortcut whose job is to close the side panel.

## Steps to reproduce

1. Load Scry as an unpacked Chrome extension in Google Chrome 147 on macOS.
2. Open the Scry side panel.
3. Press the open/refocus shortcut while the panel is already open.
4. Observe that the panel can close instead of focusing the search box.
5. Try to use a distinct close command for the side panel and observe that none exists.

## Blocked by

None — can start immediately.

## Additional context

This pairs with #0012: Command+K should become an open/refocus shortcut, not a close toggle. The close shortcut should be separately documented and remappable in Chrome's extension shortcut settings.
